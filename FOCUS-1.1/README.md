# FOCUS 1.1 Sample Data

## Overview

Synthetic, spec-compliant sample data for **FOCUS 1.1**, generated by the
model-driven tooling in [`../tooling`](../tooling).

FOCUS 1.1 adds seven columns over 1.0: `CapacityReservationId`,
`CapacityReservationStatus`, `CommitmentDiscountQuantity`,
`CommitmentDiscountUnit`, `ServiceSubcategory`, `SkuMeter`, and
`SkuPriceDetails` (50 columns total).

Providers represented: AWS, Microsoft (Azure), Google, Oracle.

## Datasets

| File | Content |
|------|---------|
| `focus_sample.csv` | 1,000-row CostAndUsage sample |

## Important: unofficial back-ported model

FOCUS has no official machine-readable requirements model for 1.0 / 1.1, so
validation uses an **unofficial back-port** of the 1.2 model filtered to the 1.1
column set. It inherits 1.2 rule logic for retained columns and is not an
authoritative 1.1 conformance reference. See
[`../tooling/FINDINGS.md`](../tooling/FINDINGS.md).

## Regenerate / validate

```bash
cd ../tooling
python -m focusgen validate --version 1.1 --data-file ../FOCUS-1.1/focus_sample.csv
python -m focusgen regen --version 1.1 --rows 1000 --out ../FOCUS-1.1/focus_sample.csv
```
