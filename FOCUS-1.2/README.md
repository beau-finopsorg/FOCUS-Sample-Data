# FOCUS 1.2 Sample Data

## Overview

Synthetic, spec-compliant sample data for **FOCUS 1.2**, generated by the
model-driven tooling in [`../tooling`](../tooling). Unlike the anonymized
real-world `FOCUS-1.0` dataset, this data is synthesized directly from the
FOCUS 1.2 requirements model, so every column's type, nullability, allowed
values, and formats follow the specification.

Providers represented: AWS, Microsoft (Azure), Google, Oracle.

## Datasets

| File | Content |
|------|---------|
| `focus_sample.csv` | 1,000-row CostAndUsage sample |

## Regenerate / validate

```bash
cd ../tooling
python -m focusgen validate --version 1.2 --data-file ../FOCUS-1.2/focus_sample.csv
python -m focusgen regen --version 1.2 --rows 1000 --out ../FOCUS-1.2/focus_sample.csv --allow-persistent
```

## Known validation note

One rule fails for every row: the `InvoiceId-C-004-C` / `InvoiceId-C-005-C`
pair in the 1.2 model is contradictory (both have empty conditions, so one
always fails). See [`../tooling/FINDINGS.md`](../tooling/FINDINGS.md).
