# FOCUS 1.4 Sample Data

## Overview

Synthetic sample data for **FOCUS 1.4**, generated by the model-driven tooling
in [`../tooling`](../tooling) from the FOCUS 1.4 requirements model
(`working_draft`).

Providers represented: AWS, Microsoft (Azure), Google, Oracle.

## Datasets

| File | Content |
|------|---------|
| `focus_sample.csv` | 1,000-row CostAndUsage sample |

## Important: validation is currently blocked upstream

The FOCUS 1.4 working-draft requirements model cannot be loaded by the FOCUS
validator — it contains a dependency cycle among the `CommitmentDiscount*`
rules (`Active-edge cycle detected`). This sample is therefore **generated but
not yet machine-validated**. Once the upstream model cycle is resolved, run:

```bash
cd ../tooling
python -m focusgen validate --version 1.4 --data-file ../FOCUS-1.4/focus_sample.csv
```

See [`../tooling/FINDINGS.md`](../tooling/FINDINGS.md) for details.
