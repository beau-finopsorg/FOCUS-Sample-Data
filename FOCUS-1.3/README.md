# FOCUS 1.3 Sample Data

## Overview

Synthetic, spec-compliant sample data for **FOCUS 1.3**, generated by the
model-driven tooling in [`../tooling`](../tooling) directly from the FOCUS 1.3
requirements model.

Providers represented: AWS, Microsoft (Azure), Google, Oracle.

## Datasets

| File | Dataset | Content |
|------|---------|---------|
| `focus_sample_costandusage.csv` | CostAndUsage | 1,000-row sample |
| `focus_sample_contractcommitment.csv` | ContractCommitment | 1,000-row sample (new dataset in 1.3) |

## Regenerate / validate

```bash
cd ../tooling
python -m focusgen validate --version 1.3 --data-file ../FOCUS-1.3/focus_sample_costandusage.csv
python -m focusgen regen --version 1.3 --rows 1000 --out ../FOCUS-1.3/focus_sample_costandusage.csv --allow-persistent
```

## Known validation notes

A small number of rules fail due to upstream model-rule defects (malformed
`CapacityReservationStatus` conditions and an inverted
`PricingCurrencyContractedUnitPrice` condition), not the data. See
[`../tooling/FINDINGS.md`](../tooling/FINDINGS.md).
